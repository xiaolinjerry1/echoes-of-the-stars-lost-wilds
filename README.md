# 群星回响：失落原野

**v1.0.0 · Godot 4.6 · 第三人称中世纪奇幻割草生存游戏**

扮演飞镖师，在森林主世界中战斗、收集经验并选择强化。身边的飞镖逐枚投出，命中后飞回；回响充满时，召唤三个会自主移动和攻击的影分身。

![飞镖战斗](art/previews/player/dart_impact_in_forest.png)

## v1.0 内容

- 一张森林主世界：营地、树林、溪流、瀑布与巨兽遗迹。
- 飞镖师完整角色、骨骼和动作；同一组飞镖的环绕、连投、归航。
- 升级后从五项能力随机抽三项，选择一项：飞镖数量与半径、攻速、攻击力、移速、影分身持续时间。
- 野狼、野猪、法师、祭司及逐渐增密的刷怪；安全营地、NPC、宝箱和草药。
- 苔冠巨兽三阶段、多招式战斗；巨大飞龙的俯冲和火球攻击。
- 跳跃、命中反馈、第三人称镜头、地图、暂停、设置与存档。
- 59项GLB模型、PBR贴图、Blender源文件和参考渲染；公开资源不包含用户提供的造型参考图。

## 从源码运行

1. 下载本仓库，或执行 `git clone https://github.com/xiaolinjerry1/echoes-of-the-stars-lost-wilds.git`。
2. 安装 **Godot 4.6 stable** 标准版（无需 .NET）。
3. 导入根目录 `project.godot`，等待首次资源导入。
4. 按 **F5**，或点击编辑器右上角“运行项目”；新游戏选择飞镖师。

当前验证平台为 Windows + Forward+/D3D12，物理引擎为 Jolt。首次加载森林会烘焙导航，耗时取决于设备。本仓库不需要 Blender、MCP 服务、账号或 API 密钥即可运行；编辑美术源文件时才需要 Blender。

命令行运行：

```sh
godot --path .
```

## 操作

| 输入 | 功能 |
|---|---|
| WASD / 鼠标 | 移动 / 转动视角 |
| 滚轮 | 调整第三人称镜头距离 |
| 空格 | 跳跃；可跃过巨兽震波 |
| 左键，可按住 | 实际环绕飞镖逐枚投出、归航 |
| 右键 | 回响满100时发动奥义·影分身之术 |
| 1 / 2 / 3 | 升级时选择强化 |
| E | NPC、营火、宝箱、草药等交互 |
| M / Esc | 地图 / 暂停、保存与设置 |

击杀掉落的经验结晶会自动吸附。死亡返回营地并清空回响，保留等级和强化。巨兽位于营地北方遗迹，飞龙位于东北方，地图分别标记“兽”“龙”。

## 自检

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . res://dev/verify_boot.tscn
```

当前生产回归覆盖94项检查，包括跳跃、逐枚投镖与回收、撞墙、移动归位、在途强化/读档、成长、分身、存档、索敌和BOSS新招式。测试只使用独立PID存档路径，不覆盖玩家真实档位。旧RPG验证脚本属于历史开发材料，不代表当前生产玩法。

## 工程结构

- `core/`：流程、注册表、存档、设置、音频。
- `scenes/`：角色、敌人、战斗、森林、BOSS和UI。
- `data/`：静态数据；旧RPG数据保留但当前注册表不启用。
- `art/models/`、`art/textures/`：运行时GLB与PNG贴图。
- `art/source/`、`art/previews/`：Blender源文件与参考渲染。
- `dev/`：开发验证；`dev/verify_boot.tscn`为当前自检入口。

## 已知限制

v1.0是首个公开源码版本，仅有飞镖师一种职业。角色面部和服装细节有简化，没有面部口型、脚底地形IK或实时布料模拟；背景音乐仍待完善。已有导航烘焙性能提示和关闭时的渲染资源泄漏提示尚未清理。其他操作系统和显卡组合尚未全面验证。
